知迹 PaperLens

把论文和笔记导入 seekdb，用混合检索秒找段落；用 PowerContext 记住你的研究方向与进度，越用越懂你。

项目简介

PaperLens 是一个文献与笔记混合检索助手，结合 seekdb（向量 + 全文 + 结构化混合检索）和 PowerContext（scoped memory）两项技术，解决科研资料管理中的三大痛点：找不到、搜不准、重复说。

项目路径：qoder/paperlens/

解决的问题

  • 找不到：论文、课程笔记、实验记录散落在十几个文件夹，靠文件名检索，内容里的段落搜不到。
  • 搜不准：关键词搜不到"意思相近但用词不同"的段落（同义表述、中英混写）。
  • 重复说：每开一个新会话，都要重新告诉助手"我在研究什么、上次看到哪"。

PaperLens 把这三件事合起来：混合检索找到段落，记忆记住你的偏好和进度，下次直接接着来。

核心功能

资料导入

Markdown / txt 按段落切块写入 chunks 表，超长段落按句号再切，保留出处。

混合检索

全文（IK 分词）+ 向量余弦两路召回，RRF 融合排序，支持 topic 过滤与加权。

记忆复用

研究方向与阅读进度写入 PowerContext scoped memory，检索时自动带上偏好加权。

出处回查

每条结果返回文档 ID、标题、片段与命中来源（fulltext / vector / 两者）。

技术结合

技术在项目中的实际作用可核对点
seekdb 唯一的数据存储与检索层：chunks 表同时建 FULLTEXT(body) WITH PARSER ik 与 VECTOR(384) 列，一次查询同时用到全文匹配、余弦距离与元数据过滤。 /search 返回的 via 字段；服务端 SQL 日志
PowerContext 记忆层：/memory/preference 写入研究方向与进度，/search 每次先读回偏好并对命中主题加权（topic boost）。 /search 返回的 memory_used、preference 字段
Qoder 承担需求拆解、代码生成、调试与网站生成；开发记录见仓库 docs/qoder-dev-log.md。 开发记录截图 + 账号 UID

快速开始

git clone https://github.com/HAN-XUAN123/PowerContext-2026.git
cd PowerContext-2026/qoder/paperlens
python -m venv .venv && source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 启动 seekdb（Docker）
docker run -d --name seekdb -p 2881:2881 oceanbase/seekdb:latest

# 配置环境变量
export SEEKD_DB_HOST=127.0.0.1 SEEKD_DB_PORT=2881 SEEKD_DB_USER=root
export POWERCX_BASE_URL=http://127.0.0.1:8000

# 导入示例资料并启动服务
python -m src.app --load-sample
python -m src.app  # http://127.0.0.1:8077

验证结果

以下为实测数据，可按 docs/verify.md 中的步骤复现：

1. 依赖自检

  • seekdb：ok，连接 127.0.0.1:2881
  • PowerContext：ok，scope scp_05w514e6d7xeh2t1j3ezetameq

2. 记忆写入并读回

curl -X POST http://127.0.0.1:8077/memory/preference \
  -H 'Content-Type: application/json' \
  -d '{"topic":"混合检索","progress":"读到第3章"}'

curl http://127.0.0.1:8077/memory/preference

返回结果：

  • preferred_topic = 混合检索
  • progress = 读到第3章

3. 混合检索（记忆复用生效）

curl "http://127.0.0.1:8077/search?q=向量与全文怎么融合&top_k=3"

返回结果：

  • memory_used = true
  • preference.preferred_topic = 混合检索

4. topic 加权效果

命中主题"混合检索"的结果分数变化：

  • 未加权：0.0327
  • 加权后：0.0443
  • 提升幅度：+35%

说明 PowerContext 的偏好确实被用于检索排序。
