# 任务
VIP 折扣率超过 30% 时必须拒绝并抛 ValueError，不允许静默截断

# 必须遵守的规格
## SPEC-DISCOUNT-001 — SPEC-DISCOUNT-001 基础折扣
普通会员订单按原价结算，不接受任何折扣参数。
## SPEC-DISCOUNT-002 — SPEC-DISCOUNT-002 VIP 折扣范围
VIP 会员订单享受 `discount_rate` 折扣，取值范围为 **[0, 0.30]**（含 0 与 0.30）。

- `discount_rate = 0` 表示不打折，按原价结算。
- `discount_rate = 0.30` 表示最高档折扣，超出该值即违反本规格。
## SPEC-DISCOUNT-003 — SPEC-DISCOUNT-003 超限必须拒绝
当调用方传入的 `discount_rate` 大于 0.30 时，实现必须抛出 `ValueError`，
且异常信息需要包含 `discount rate exceeds limit`。不允许静默截断为 0.30，
也不允许按 0.30 结算后返回。
## SPEC-DISCOUNT-004 — SPEC-DISCOUNT-004 负值必须拒绝
当 `discount_rate` 小于 0 时，实现必须抛出 `ValueError`。
## SPEC-DISCOUNT-005 — SPEC-DISCOUNT-005 金额精度
折扣后金额保留两位小数，采用四舍五入（ROUND_HALF_UP）。
## SPEC-DISCOUNT-006 — SPEC-DISCOUNT-006 金额边界
订单原始金额必须为正数（> 0），否则抛出 `ValueError`。
原始金额为 0 或负数时不得进入折扣计算分支。

## pricing.py（符号：apply_discount）
```python
"""订单金额计算（业务工程示例）。

当前实现只做了基础的负值检查与两位小数处理，
尚未实现 SPEC-DISCOUNT-003 要求的「上限必须拒绝」。
"""

from __future__ import annotations

from decimal import Decimal, ROUND_HALF_UP


VIP_MAX_DISCOUNT = Decimal("0.30")


def apply_discount(amount: Decimal, discount_rate: Decimal, is_vip: bool) -> Decimal:
    """按会员类型与折扣率计算应付金额。

    Args:
        amount: 订单原始金额。
        discount_rate: 折扣率，0 表示不打折。
        is_vip: 是否 VIP 会员。

    Returns:
        折扣后金额，保留两位小数。

    Raises:
        ValueError: 金额非正、折扣率为负、非 VIP 传了折扣。
    """
    if amount <= 0:
        raise ValueError("amount must be positive")

    if not is_vip:
        if discount_rate != 0:
            raise ValueError("discount is only available for vip members")
        return amount.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

    if discount_rate < 0:
        raise ValueError("discount rate must not be negative")

    # TODO(SPEC-DISCOUNT-003): 缺少上限校验
    payable = amount * (Decimal("1") - discount_rate)
    return payable.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

```
